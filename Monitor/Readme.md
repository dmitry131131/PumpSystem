# Pump System Monitor

## Сборка и запуск

Из каталога `Monitor`:

```bash
cmake -S . -B build/Release -DCMAKE_BUILD_TYPE=Release
cmake --build build/Release
./build/Release/bin/Monitor
```

Укажите путь к Master (по умолчанию `/dev/ttyUSB0`) и нажмите «Подключить».
Кнопка «Найти Master» перебирает USB-последовательные порты `/dev/ttyUSB*`
и `/dev/ttyACM*` через `serial::list_ports()`. Monitor ждёт ответа на регистрацию
до трёх секунд на порт и подключается к первому ответившему Master. Во время
проверки отображается текущий порт, а поиск можно отменить.

После ответа Master выберите насос, задайте направление и количество оборотов.
Текущая прошивка поддерживает до 20 целых оборотов за одну команду при
200 полных шагах на оборот и делении шага 1/16. Скорость ручного вращения
фиксирована на 6 об/мин.

Monitor сообщает об отправке команды по UART. В текущем протоколе нет
подтверждения выполнения движения насосом.

## Настройки насосов

Во вкладке «Настройки насосов» можно добавить насос по номеру (3–255) до
подключения Master. Выберите насос, введите название и объём за один оборот
в микролитрах, затем нажмите «Применить». Для дробного объёма можно использовать
запятую или точку. Пустое поле означает, что объём пока не задан.

«Сохранить JSON» записывает настройки всех известных насосов в один файл.
«Загрузить JSON» добавляет недостающие насосы и обновляет настройки по номеру.
Статусы поступают от Master. Новые насосы из файла отображаются без связи до
получения их статуса. Насосы, обнаруженные Master, доступны для настройки в той
же вкладке.

Журнал `monitor.log` дополняется в рабочем каталоге приложения. Строки UART
содержат время UTC, направление TX/RX, название команды, адрес, длину полезной
нагрузки и байты кадра в шестнадцатеричном виде. Строки `SEARCH` показывают
начало поиска, проверяемый порт (`CHECKING`) и результат каждой попытки:
`FOUND` — Master ответил, `TIMEOUT` — ответа нет, `OPEN_ERROR` — порт не открылся,
`UART_ERROR` — ошибка обмена, `CANCELLED` — проверка отменена. При ошибке
поле `detail` содержит её причину. `NO_PORTS` означает, что подходящих портов нет,
а `NOT_FOUND` — что ни одна проверка не подтвердила Master.
